**Sunset Palms Cover Studio** — a fully offline web app that turns your photo into multi-panel GTA-style cover art. Pick a layout (Hero, Trio, Quad or Strip), drop one photo across the panels or a different photo in each, drag each panel to pan it, zoom and fit it, write a bold outlined caption, pick a Vice City neon-sunset colour grade (Neon Sunset, Vice Night, Palm Gold or Pop Flash), and export the cover as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Everything is drawn on canvas with system fonts and the two bundled sample photos; no network request, no upload, no Rockstar artwork or fonts — the lettering, skyline and grades are all original.

## Run it

```sh
node serve.ts
# then open http://localhost:8080

# hand the entry in:
MAKEFUN_OUTPUT_DIR=out node main.ts
```
